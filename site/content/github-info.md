## Recent updates worth knowing

- **Copilot code review effort levels are now generally available** — teams can tune how thorough Copilot's automated PR reviews are, balancing review depth against speed. *(Source: GitHub Changelog)*
- **Copilot cloud agent reasoning level is now customizable** — you can adjust how much reasoning the cloud agent applies to a task before it starts working. *(Source: GitHub Changelog)*
- **Trigger Copilot automations from comments** — teams can kick off Copilot-powered automations directly from issue or PR comments, making it easier to hand off follow-up work. *(Source: GitHub Changelog)*
- **Branch protection rules can now be auto-migrated to repository rulesets** — a guided migration path helps repos move onto the newer, more flexible rulesets model. *(Source: GitHub Changelog)*
- **Copilot usage metrics API now includes agent app activity** — gives admins better visibility into how Copilot agents are being used across an organization. *(Source: GitHub Changelog)*
- **GitHub Universe 2026 schedule has launched** — the annual GitHub developer conference now has its session lineup published. *(Source: GitHub Blog)*
