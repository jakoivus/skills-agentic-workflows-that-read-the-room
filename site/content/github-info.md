## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent GitHub Blog highlights

- **Agentic workflows are the new normal.** Posts like "From coder to orchestrator: How agents shift the role of a developer" and "Your contributors are AI-first now. Is your project?" explore how AI agents are reshaping day-to-day development work. (Source: github.blog)
- **Reviewing AI-generated code at scale.** "Turn one giant AI-generated pull request to a reviewable stack" offers practical tips for breaking large agent-authored PRs into reviewable chunks. (Source: github.blog)
- **Copilot app fundamentals.** The "GitHub Copilot app for Beginners" series covers writing your first prompt and managing your work inside the Copilot app — a good starting point for newcomers. (Source: github.blog)
- **Copilot CLI in the real world.** "How the GitHub legal team used Copilot CLI to streamline their workflows" shows a non-engineering use case for the CLI agent. (Source: github.blog)

## Recent GitHub Changelog updates

- **Copilot code review effort levels are generally available**, letting teams tune how deeply Copilot reviews pull requests. (Source: github.blog/changelog)
- **Agent plugins 1.0** shipped for VS Code, Copilot CLI, and the Copilot app, extending what Copilot agents can do out of the box. (Source: github.blog/changelog)
- **Rule insights dashboard** is now generally available, giving organizations visibility into how repository rulesets are enforced. (Source: github.blog/changelog)
- **GitHub Copilot app Customize tab** is generally available, letting developers tailor the Copilot app experience.  (Source: github.blog/changelog)
- **Push rules in rulesets now support path exceptions**, making branch protection easier to fine-tune for specific files or folders. (Source: github.blog/changelog)

## Community workflow examples

- The [github/awesome-copilot](https://github.com/github/awesome-copilot) repository curates ready-to-use GitHub Actions agentic workflows (in its `workflows/` directory), including a daily issues report, OSPO contributor and stale-repo reports, and automated relevance checks — useful references for building your own Copilot-powered automations.
